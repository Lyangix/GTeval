# SNP lists

Variant definitions used for the Height, BMI, and WHR gPRS scores. Each set has
an annotated CSV and a one-ID-per-line `.snplist` file with no header.

| Trait | GWS | Suggestive | Liberal |
| --- | ---: | ---: | ---: |
| Height | 2,313 | 16,020 | 30,937 |
| BMI | 435 | 4,788 | 13,980 |
| WHR | 172 | 1,991 | 7,485 |

The sets contain 78,121 trait/threshold entries; variants may recur between sets.
GWS uses `P < 5e-8` and LD r-squared 0.1. Suggestive uses `P < 1e-5` and
LD r-squared 0.5. Liberal uses `P < 1e-3` and LD r-squared 0.5.
The original documentation records PLINK pruning with `--indep-pairwise 250 1`.
Sets were pruned separately and need not be nested.

## Files

Names follow `{trait}_{threshold}`, in lowercase. For example:

- [height_liberal.snplist](height_liberal.snplist): SNP IDs only.
- [height_liberal_gprs_snp_effect_allele_weights.csv](height_liberal_gprs_snp_effect_allele_weights.csv): variant annotations and weights.
- [gprs_snp_counts.csv](gprs_snp_counts.csv): counts, thresholds, and source filenames for all nine sets.

The CSVs are unchanged copies of the original `gprs_snp_tables/` tables,
generated by `make_gprs_snp_tables.R` from the score-input files recorded in
`Source_file`. Each ID-only list preserves its CSV's variant order.
No participant-level dosages, IDs, phenotypes, or individual PRS values are included.

## Columns

| Column | Meaning |
| --- | --- |
| `Trait`, `Threshold` | Trait and variant set |
| `P_value_threshold`, `LD_r2_threshold` | Selection and pruning cutoffs |
| `SNP` | Original `chr:position:allele1:allele2` identifier, not an rsID |
| `Chromosome`, `Position`, `Allele_1`, `Allele_2` | Fields parsed from the identifier; allele order does not establish REF/ALT |
| `Effect_allele`, `Other_allele` | Counted allele and the other encoded allele |
| `gPRS_weight` | Signed source-GWAS score weight per counted effect allele |
| `Source_file` | Original score-input basename |

**The source tables do not specify the genome build, source-GWAS publication,
or weight units.** Coordinates are preserved without conversion. Establish the
build and allele coding before matching another genotype dataset. The tables
also do not specify score summation versus averaging or missing-dosage handling.

## Use a list

From the repository root:

```r
variants <- read.csv("snp_lists/height_liberal_gprs_snp_effect_allele_weights.csv")
snp_ids <- readLines("snp_lists/height_liberal.snplist")
# For a local matrix whose column names match these identifiers:
# G_selected <- G[, match(snp_ids, colnames(G)), drop = FALSE]
```

The ID-only files also work as PLINK `--extract` lists when the variant IDs
match. The modeling functions use the genotype matrix and PRS you supply;
they do not automatically read these lists. The simulation uses invented variants
and weights.
